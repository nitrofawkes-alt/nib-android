# Nib Android shell

A minimal Capacitor shell for the published Nib web app. It loads https://nib-companion.floot.app and includes nib-floating-window-cap@1.1.0 so Android can provide the floating overlay, roaming companion, background wake service, and related native behavior.

GitHub Actions builds a directly installable debug APK. Open Actions > Build Nib APK, wait for the run to finish, then download the Nib-debug-apk artifact and install app-debug.apk on Android.
